# 多人 Agent 协作

让多个人带着各自的 coding agent，在同一个 Git 项目中协作开发。

项目处于构思阶段，尚未实现功能。

## 项目方向

- 支持不同成员在各自电脑上使用自己的 agent 和账号。
- 优先探索 Codex CLI 和 Claude Code 的接入，并为其他 agent 预留适配接口。
- 共享任务、接口约定、项目决策和工作进度。
- 通过独立分支、代码审查和集成验证汇总成果。
- 每位成员保留对本地执行、权限和预算的控制。

## 首个验证场景

两个人在两台电脑上，分别使用 Codex CLI 和 Claude Code，为同一个仓库完成一个具有前后端依赖的功能。

验证协作是否缩短交付时间、减少人工传话，并控制集成返工。
